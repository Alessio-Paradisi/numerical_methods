================================================================================
FREE SCALAR FIELD ON THE LATTICE - README
================================================================================

PHYSICS BACKGROUND
------------------

The goal is to compute thermodynamic observables of a free scalar field in 2D
(1 time + 1 space dimension) using lattice Monte Carlo methods.

The system is discretized on a N_T x N_S lattice where N_T is the number of sites
in the temporal direction and N_S in the spatial direction. Each site carries a
scalar field value phi_n. The temperature is inversely proportional to the temporal
extent: T = 1 / (N_T * a), where a is the lattice spacing.

The mass parameter entering the simulation is the dimensionless lattice mass:
    M_HAT = m * a = 1 / N_T

so that the physical mass m is kept fixed as N_T varies.

The three observables measured are (eq. 15.1.9 of the notes):

    O1 = (1/N_T*N_S) * sum_n  m_hat^2 * phi_n^2          (mass term)
    O2 = (1/N_T*N_S) * sum_n  (phi_{n+x} - phi_n)^2      (spatial kinetic term)
    O3 = (1/N_T*N_S) * sum_n  (phi_{n+t} - phi_n)^2      (temporal kinetic term)

These combine to give the renormalized energy density:

    epsilon / T^D = (N_T^D / 2) * ( <O1+O2-O3>_Nt - <O1+O2-O3>_Nt_bar )

where the subtraction removes UV divergences by normalizing with a zero-temperature
reference simulation (see below).


ZERO TEMPERATURE NORMALIZATION
-------------------------------

The raw values of O1, O2, O3 contain UV divergences that are temperature-independent.
To cancel them, for each finite temperature simulation (N_T, N_S, M_HAT) a reference
simulation is run at T ≈ 0 using:

    N_T_bar = N_S    (large temporal extent → very low temperature)
    same N_S and M_HAT as the finite temperature run

The renormalized observable is then:
    <O_i>_renorm = <O_i>_Nt  -  <O_i>_Nt_bar

The output files data_O{1,2,3}.txt contain both rows (distinguishable by the N_T
column), so the subtraction can be performed in post-processing.


FILES
-----

free_field.c    C simulation code. Reads parameters from parameters.h, runs the
                MCMC and appends results to data_O{1,2,3}.txt.

free_field.py   Python driver. Manages the parameter scan, writes parameters.h
                before each run and calls the C executable.

parameters.h    Auto-generated by free_field.py. Contains: N_T, N_S, M_HAT.


HOW THE TWO CODES INTERACT
---------------------------

    free_field.py writes parameters.h
         |
         v
    free_field.c compiled and run
         |
         v
    results appended to data_O{1,2,3}.txt
         |
         v
    Python moves to next parameter pair

For each (N_T, N_S) pair Python runs two simulations back to back:
  1. Finite temperature:   N_T, N_S, M_HAT = 1/N_T
  2. Zero temperature ref: N_T_bar = N_S,  same N_S and M_HAT


PARAMETER SCAN
--------------

    N_T:   4, 5, 6, 7, 8, 10
    N_S:   4*N_T, 6*N_T, 8*N_T  for each N_T

    Total: 18 finite temperature + 18 zero temperature = 36 simulations


THE SIMULATION (free_field.c)
------------------------------

For each run the C code:
  1. Cold start: initializes all phi_n = 0
  2. Thermalization: 10000 sweeps discarded to reach equilibrium
  3. Measurement: 50 million sweeps, measuring O1, O2, O3 after each
  4. Statistics: mean and jackknife error for each observable
  5. Output: appends  mean, error, N_T, N_S  to data_O{1,2,3}.txt

Each sweep consists of N_T * N_S single-site updates. Each site update:
  - Randomly selects a lattice site
  - 20% probability: heat-bath update (samples from exact conditional Gaussian)
  - 80% probability: microcanonical update (deterministic energy-preserving reflection)

The combination of the two methods reduces autocorrelation time significantly
compared to using heat-bath alone. Errors are estimated with the jackknife method
with automatic block size selection to account for autocorrelations.


OUTPUT FORMAT
-------------

Each line in data_O{1,2,3}.txt:    mean,  error,  N_T,  N_S

Example:
    0.123456, 0.000123,  4, 16    <- finite temperature  (N_T = 4)
    0.098765, 0.000098, 16, 16    <- zero temperature ref (N_T_bar = N_S = 16)


HOW TO RUN
----------

    python3 free_field.py

Requires: gcc, pcg32 library at /usr/local/lib/pcg32.c
